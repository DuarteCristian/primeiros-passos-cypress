# My cypress automation

this project utilizes Cypress to automete testing of a login feature and a user update a feature.
Cypress is a JavaScript-based end-to-end testing framework that allows developers to write test and execute them in a real browser.

## Installation
```bash
npm install
```
>it is necessary to have **NODE** intalled
>
### Running
```bash
# you open the Cypress UI
npx Cypress open

# Run the automation by command line
npx cypress run
```
